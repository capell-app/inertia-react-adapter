# Capell Inertia React Adapter

<!-- prettier-ignore-start -->

## What it does

Capell Inertia React Adapter supplies the React side of Inertia-powered themes.

## Do I need to do anything?

Usually no. It works behind the scenes once installed. You will see its effect only if you use a React-based Inertia theme.

## Where it shows up

In how a React Inertia theme renders; there is no separate screen to operate.

## Good to know

- Install this only if your Inertia theme uses React.
- It works alongside Capell Inertia; install that too.
